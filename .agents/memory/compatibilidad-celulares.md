---
name: Compatibilidad con celulares
description: Regla del usuario para que las modificaciones del proyecto sigan funcionando en celulares.
---

Todas las modificaciones de este proyecto deben ser compatibles con celulares también.

**Why:** el usuario lo pidió.

**How to apply:** al modificar la app, preservar el uso en pantallas de teléfono y comprobar el diseño móvil cuando haya interfaz afectada.
