---
name: Ubicación de entrega
description: Selección de destino del cliente y compatibilidad con pedidos y clientes anteriores.
---

El cliente no debe escribir su dirección en el carrito. Debe tener dos opciones: usar su ubicación exacta o seleccionar la ubicación en un mapa.

**Why:** El usuario pidió sustituir el campo «Dirección y referencia» por esas dos opciones.

**How to apply:** Solicitar el GPS solo al pulsar la opción correspondiente. La alternativa manual permite marcar y confirmar un punto del mapa, no escribir coordenadas. Nunca usar el centro inicial del mapa como si fuera la ubicación real del cliente. Si falla el GPS, informar el problema y permitir elegir en el mapa.

Conservar las direcciones de pedidos anteriores y la recepción de direcciones de clientes antiguos mientras el carrito nuevo exige seleccionar una ubicación.

**Why:** La app también tiene APK existentes; convertir el nuevo formulario en una prohibición inmediata de direcciones antiguas rompería esos clientes y los pedidos históricos.

**How to apply:** El punto confirmado pertenece al pedido y debe conservarse para que el negocio y el repartidor puedan consultarlo. No sustituir ni sobrescribir automáticamente la dirección del perfil del cliente.
